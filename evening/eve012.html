模型选择与配置快速上手

百度千帆 → 模型服务 → 接入点ID复制

本次演示使用 DeepSeek 3.1 模型，但百度千帆支持文本、图像、视频、语音等多种服务类型可自由选择。配置时需通过百度千帆页面点击"模型服务"，选择所需模型后复制接入点ID，粘贴至 open call 配置文件中即可完成对接。

⚙️ 配置要点：
• 参考千帆示例文档正确填写 API ID
• API ID 错误会导致 API 不通
• 支持多模型切换，可在模型管理界面操作

费用透明化查询与服务部署

模型服务 → 在线推理 → 计费方式查看

担心费用问题？回到模型服务页面点击"在线推理"子选项，选择具体服务和模型后可查看当前计费方式。免费额度会有明显指引，点击详情可查看按量付费的调用量和费用。

传统方式用 Vim 编辑配置文件修改 API key 较复杂，我们提供了更友好的方式——直接复制文档中的两条命令，无需编辑文件即可完成修改，只需填写 API key 和模型 ID。

— 李璐

简易方式：复制命令 → 填写 API key + 模型 ID → 完成配置

核心问答：服务器、备案、技能 API 完全解答

实操困扰 → 专家解答
❓ 服务器如何选择？
原则：根据模型地区选择——使用海外模型建议海外部署；追求性价比+国产模型首选国内部署。
好消息：百度智能云提供免费服务器（每人1台），配置为 2 CPU、4G 内存、4M 带宽、200G 硬盘，需从活动链接购买，可能需切换地域。
❓ 今晚部署需要 ICP 备案吗？
无需备案。本次只是在云里部署服务器供个人使用，而非搭建网站供他人访问，因此无需 ICP 备案。
❓ Skill 如何调用？
方式一（显式）：直接告知 AI 使用某个 Skill
方式二（隐式）：AI 自动理解需求并调用相应 Skill
成本优化：国内有多个免费 Skill API，百度智能云也提供体验额度，新用户额度较多，每天凌晨 0 点刷新额度。
❓ TOKEN 购买如何最划算？
方案一：按 TOKEN 包/增量包购买——额度大、划算，适用于多个模型
方案二：按需付费——适合测试新模型或对比模型能力
