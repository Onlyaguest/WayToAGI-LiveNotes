阿里云百炼 AI Agent 创客开发实战课

讲师：许键 | WaytoAGI
2025年9月5日 19:54-22:30

平台易用性与模型体验

阿里云百炼基础入门

上手便捷：支持支付宝/淘宝扫码登录，无需复杂操作即可开始使用。平台集成千问家族多个模型，包括8月13日发布的千问Image（画图）、8月18日发布的改图模型，以及千问Plus、Coder等常用模型。

模型丰富性：展示用千问Image生成国庆海报效果良好。提示词质量直接影响生成结果——通过观察模型深度思考过程可持续优化提示词功力。建议开通通义千问Plus模型，该模型在多数场景能满足需求。

智能体应用创建与工作流搭建

从模板到自定义开发

应用创建方式：

  • 克隆应用：直接克隆应用广场模板，点击"复制此应用"快速上手
  • 空白创建：在应用管理中创建工作流应用，编写提示词（代表用户认知，影响LLM效果）
  • 示例：创建"温柔班主任"智能体引导学生解决鸡兔同笼问题，展示实际应用价值

工作流搭建：通过拖放组件、连线并配置提示词完成。简单版本可通过变量应用将部分配置开放给用户。进阶版本使用API方式（如Banana模型），实现代码间通信，支持图片生成、视频生成等能力。

"工作流就像搭积木连线——先简单理解，多用几次就清晰了。"

— 许键

API接入与多平台融合应用

工作流驱动与生态联动

API概念与应用：API如餐馆服务员，实现代码与代码间通信。配置步骤包括：找到API工具 → 配置请求方法/地址/请求头 → 获取API Key替换 → 集成到应用。视频生成示例展示上传任务+检查完成状态两步流程，免费额度约50次。

钉钉AI表格融合：在表格输入需求文档 → 自动拆解 → 分配给AI程序员 → 生成Python代码 → 自动运行判断结果。支持批量多语言翻译、工作流发布到钉钉AI表格实现任务自动化。

外部模型接入：接入Gemini Flash 2.5等外部API，支持文生图、图生图、多图多参处理。工作流通过变量处理节点传递前端参数，使用代码节点进行参数转存。可用于短剧分镜、电商多图融合等场景。

简单玩法：意图分类将闲聊与生成图片分开，调用通义万象文生图模型

高级玩法：接入Banana API后工序简化，直接返回图片链接；通过流式输出提高体验；条件判断区分输入情况

新闻获取与内容创作实战

MCP配置与提示词优化

新闻智能体创建：使用火爬工具全网爬取知乎、微博等数据 → 按需求排序展示 → 百炼平台复刻实现。通过应用管理创建应用，选择合适模型，编写优化提示词，配置自定义MCP服务。可本地部署方便家中获取新闻。

封面制作与成本优化：使用Banana Nano + MCP方法制作封面，成本低至三分钱/张。配置方式：选择脚本部署 → Python UVX启动工具。案例制作页面每种风格都有提示词可一键复制使用。

"OpenAI的SPEC概念：让人和机器在共同语言环境中沟通。用ASCII语言明确尺寸、风格、主体等设计要求，与AI进行有效沟通。"

— 陈凤

提示词编写思路：规范化沟通是关键。工作流分两步：(1)输入标题 → 智能分行生成英文提示词；(2)调用MCP组装画面。通过调整提示词可优化生成效果，生成后需保存正确图片名称避免引用错误。

核心要点

  1. 平台入门零门槛：支持支付宝/淘宝登录，模型丰富（千问Image、改图、Plus、Coder等），建议从开通Plus模型开始
  2. 提示词决定效果：优质提示词比模型本身更重要，代表用户认知，可通过观察深度思考过程持续优化
  3. 应用创建双路径：快速上手克隆模板，深度应用从空白创建编写提示词，温柔班主任案例展示实际应用价值
  4. API是工作流核心：配置请求方法/地址/Key即可实现图片/视频生成；接入Banana后工序大幅简化，视频生成免费额度约50次
  5. 钉钉+百炼生态已打通：需求自动拆解、代码自动生成运行、多语言批量翻译，显著提升工作效率
  6. MCP配置成本低廉：Banana Nano+脚本部署约三分钱/张，每个风格都有现成提示词可复用
  7. SPEC规范化沟通法：用ASCII语言明确设计要求（尺寸、风格、主体），让AI准确理解意图，通过迭代调整优化效果
