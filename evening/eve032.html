Claude Code 核心工具深度解析

MCP、Skill、Sub Agent、Command 四大工具

MCP：外部工具调用协议

MCP 是 Anthropic 推出的协议标准，能让大模型调用外部工具和数据。以 Chrome DevTools MCP 为例，可获取网站信息、进行调试和截图，对网页开发极为有用。需注意安装成功概率不超50%，调用工具会大量消耗TOKEN。

Skill：高效能力包方案

Skill 是可复用的技能包，将专业知识打包分享。运行时仅输入和输出消耗TOKEN，过程零消耗，速度快且经济高效。支持两种创建方式：一是利用现有资料通过 Script Skill Creator 生成并优化；二是完成任务后直接创建。Skill 全局注册后可跨项目使用，自动下载和安装流程。演示案例包括生成PPT（内容合理但需模板）和生成图片（基于网站内容生成图文一致的图片）。

Sub Agent：专业化角色分配

Sub Agent 为特定角色分配特定任务，拥有独立上下文，表现更专业稳定。支持项目级和个人级两种使用方式，创建时可选择调用工具、模型版本（推荐Opus）。创建后可直接使用或下载他人创建的 Sub Agent。

Command：系统级与自定义命令

Command 分为系统级和自定义两类。系统级包括：init 命令扫描项目文件生成 Claude MD 文档作为上下文、/mcp 查看MCP安装状态、/model 切换模型版本。自定义命令可实现如推送代码到 Github 等功能，创建后需重启窗口加载。

常见问题与安装指南

401报错、代理配置、工具选择

安装问题排查

401报错源于Anthropic auth TOKEN配置问题：官方账号配置TOKEN，第三方账号配置API key。Claude 一键安装命令需要科学代理支持，命令行需额外配置代理参数。CC switch 配置完毕后重启仍生效，无需常驻，重新配置时打开即可。

API 选择建议

重度使用：选择每月订阅方案，包括中转或国产大模型订阅，虽有额度限制但整体性价比高。尝试使用：选择 DeepSeek、Kimi、智谱 MiniMax 等国产大模型，价格低廉，适合初期探索。

Skill 与其他工具对比

Skill vs 提示词：Skill能力范围更广，不仅规范大模型还能执行复杂任务（如PPT包含Python和JS代码）。Skill vs Coze组件：Skill是可修改的文件夹，按需调整；Coze组件是黑盒，无法修改。Claude Code vs Coze：Claude Code是通用智能体自由度高，Coze 像超市封装粗颗粒度功能。

Skill 的核心优势在于"过程不消耗TOKEN"——仅输入输出计费，整个执行链路零成本，这使其成为构建可复用能力体系的最优方案。相比提示词的规范功能，Skill 可打包完整的代码逻辑和工具链；相比Coze的黑盒组件，Skill 提供完全的可修改性和透明度。

— Ben（Claude Code 进阶教程主讲）

核心收获 · 7点速记

  1. MCP安装理性预期：成功率不超50%，安装前做好备选方案，安装后要考虑TOKEN消耗
  2. Skill零过程消耗模式：输入输出计费，过程免费，是构建高效自动化流程的理想选择
  3. Sub Agent独立上下文优势：为特定角色分配专业任务，稳定性和专业度显著提升
  4. Command系统化管理：系统级命令快速扫描项目，自定义命令自动化常用操作流程
  5. 配置代理是必要条件：一键安装命令失败多源于代理缺失，命令行需额外配置
  6. API选择按使用深度分层：重度用户选订阅，探索用户选国产模型，性价比最优
  7. Skill全局注册跨项目复用：一次创建，全项目可用，逐步积累个人能力库
