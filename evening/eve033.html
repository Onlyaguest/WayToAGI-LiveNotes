Claude Code 安装与配置核心方案

01 | 环境部署

Claude Code 提供两种安装方式：有梯子可直接配置代理安装；无梯子需安装nodejs依赖并通过命令行复制安装。账号模式分为官方账号（易被封）、中转账号（解决账号网络问题）、国产大模型（能力有差距）三种，可根据需求选择。API配置以DeepSeek为例，通过获取API key并用CC Switch工具便捷配置。

三层账号解决方案：
  • 官方账号 → 中国不友好易被封
  • 中转账号 → 解决账号和网络问题（推荐）
  • 国产大模型 → 能力有差距但可用

Claude Code 功能与技能体系

02 | 应用实践

Claude Code插件界面友好，避免命令行恐惧。提供Plan、Bypass permission、Ask before Edit等多种模式切换。Skill是Claude Code的技能包，可将任务打包（如做PPT、写文章），分为官方技能和自编写技能两类。演示包括创建待办清单、迭代页面样式和功能、使用Git进行版本管理等实战操作。

Skill类型与用途：
  • 📊 官方做PPT技能 → 直接读取技能文档执行
  • ✍️ 写作技能 → 按风格生成高质量文章
  • 🎲 自建掷骰子skill → 通过Skills Creator创建娱乐功能

Cloud Skills方法与生态推广

04 | 工具生态

Cloud Skills方法相比搭建MCP Server和AI Agent工作流更便捷，只需会写文档即可编排。已验证效果良好，但因用户了解不足导致普及率低。彭程计划开展系列直播课讲解Claude code、CodeX的快速入门、配置、MCP和Skills使用及实战技巧，展示Claude code在编程外做文章、PPT等多场景应用。

"Claude code不仅可用于编程，还能做写文章、做PPT等其他事。Cloud Skills方法好用且简单，比搭建MCP Server更便捷——只要会写文档就能编排。"

💡 核心要点

  1. 双轨安装方案：有梯子直接代理，无梯子用nodejs+命令行，中转账号是最实用选择
  2. Skill是核心生产力：官方和自编技能可大幅提效，不仅限编程场景
  3. 无代码应用可行：零基础通过与AI交互可完成完整App开发（如穿衣橱应用）
  4. Git版本管理必学：如同游戏存档系统，可回滚版本，适用团队协作
  5. AI CODING训练营开放报名：第四期1月开营，课程定制化，提供搭子团支持
  6. Cloud Skills普及机会：低门槛高效率，需持续科普推广
  7. 多模式切换灵活：Plan/Ask before Edit等模式满足不同开发场景需求
