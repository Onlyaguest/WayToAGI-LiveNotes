千问 Image 核心突破：文字渲染能力

原生文字渲染是千问 Image 最核心的技术突破。吴晨飞博士团队针对中文生成困难的痛点，从数据和模型两个维度进行攻关：

  • 数据层面：设计复杂数据处理流程，获取带有文字渲染的优质数据
  • 模型设计：采用 OCR 能力强的轻 2.5 VO 编码文本，使用 20B MMDIT 模型处理文本-图像整体注意力，双流结构提升细粒度文本控制

一级汉字准确率达 97%（GPT-4V 为 68%）；二级汉字准确率 41%（GPT-4V 为 16%）

设计理念："易字稳、难字能写" — 常用字稳定生成，生僻字多次尝试也大概率能生成，还可通过图像编辑能力修饰字的偏旁部首。

提示词使用技巧与创意案例

提示词核心原则

提示词本质是区隔数据，集中想要的优质数据。不同模型因训练数据不同，所需提示词有差异。

四大实用技巧

✓ 保持训练推理一致
训练数据中文字用引号引起，推理时也应用引号括起，避免训练-推理差距。

✓ 避免使用否决词
摒弃"不要生成什么什么"等否定表述，以免影响生成效果。

✓ 明确文字位置和风格
复杂逻辑用相对位置法（定义文字间逻辑关系），简单位置用绝对位置法（左上角、右上角等）；始终明确风格（如纪实摄影风格）。

✓ 详细清晰描述
明确邀请函上的名字日期等信息，详细描述画面内容、主体特征，能显著提高生成效果。

创意应用案例

  • 手办生成：清晰提示词描述照片→角色形象→建模过程，轻松生成手办效果
  • 多视图生成：简单提示词即可实现前后左右视图，为 3D 建模提供基础
  • 艺术字体编辑：输入字体变 3D 效果并悬浮街道，空间漂浮感和背景模糊处理完美
  • 图像组合迁移：衣服、鞋类迁移到模特身上，产品图贴入手中，广告设计实用价值高
  • 线稿上色：官方 Twitter 展示线稿上色案例，若效率进一步提升将大幅助力设计师
