月入万刀的 Agent 开发者经验分享

2025-07-31 | 19:56-22:38 GMT+8 参会人数 556+

技术体系与开发方法

彬子code模式讲解 × 火火扫盲 × 安仔工作流类比

Code 模式核心能力：支持 Python、JS 基础语法，可在 function call 返回 JSON 格式时提取对应 value 值。以 SUB maker 为例，通过 JSON 解析实现元素结构化展示。

Machine vs Bot 区分：Machine 是装工具的箱子（接入 GPT、DeepSeek 等），Bot 应用是封装工作流的小应用。平台提供 2.0 内测全自动、1.0 简单创建、本地部署三种方式。

工作流三要素类比：安仔提出"牛马员工"概念——有什么（用户输入）、做什么（具体操作）、交付什么（输出结果）。以图片编辑工作流为例，用户上传→选择功能→对应节点处理（去水印、创意设计等）→交付结果。

创作者激励与平台福利

算力提升 × 橱窗收益 × 学习资源生态

成为 MyShell 创作者后，算力从 60 提升到 600，每次运作消耗 5 积分；平台承担新手培训、围炉会议等全部费用，创作者无需参与收费项目——这是真正的开放共赢模式。

— 平台方周俣博

算力与成本：创作者通行证激励机制，算力充足支持各类工作流测试，包括 GPT、DeepSeek 等高端功能调用。

收益模式：平台提供橱窗展示（类似淘宝橱窗），创作者需优化应用展示；月结形式公布收益排行榜，展示前三名详细数据与前十名排行。

学习生态：每周围炉会议由大佬分享制作经验，社区提供教程、文档、新人教程，支持与大佬一对一技术问答。

改图 Agent 实战与大模型内化

从状态机到 GPT 能力融合

状态机核心：Shell Agent 1.0 改图神器搭建基于状态机设计。用户点击"开始编辑"上传图片→向导展示交互按钮→选择功能后触发对应"牛马员工"节点处理。

大模型能力内化：GPT 出现前，改图需求需前置大模型进行意图识别（困难重重）。如今大模型能力内化，可通过添加翻译节点（解决 Context 中文不支持）、结合 GPT 节点提升智能性。强调挖掘被忽略的用户需求——以海报场景为例，大模型能优化节点、提升用户交互量与出图评级。

功能拓展策略：可增加 GPT 生成按钮解决模型效果问题；换装、换脸等创意玩法受欢迎。鼓励创作者大胆创新，结合 1.0 基础概念有助于 2.0 版本调试。

新手创作学习路径

循序渐进 × 云端优先 × 动手实践

学习阶梯：

  • 第一步：用彬子 Code 方法，以较少节点跑通首个工作流（快速成功感）
  • 第二步：尝试安仔方法，利用 MyShell 原生节点搭建（系统理解）
  • 第三步：有 Confui 基础可尝试 Runninghub 复刻工作流（深度拓展）

云端优先原则：新手推荐使用云端方式创作，避免本地部署环境复杂性和 API 对接难度。马帅已将 Share Agent 和 Config UI 搭建过程云端化，社区经验同学可迁移经验到 Share 建设。

动手创作驱动：讲师鼓励先做出一个简单作品，获得正反馈后加入开发者群与他人交流。强调 1.0 版本是基础——掌握概念便于 2.0 版本调试。

✨ 核心要点总结

  1. 三要素工作流思维：设计任何 Agent 时牢记"有什么→做什么→交付什么"，这是理解 ShareAgent 与 CostAgent 本质区别的关键
  2. 算力充足 + 免费生态：创作者算力从 60→600 十倍跃升，平台全额补贴培训费用，真正零成本启动
  3. 大模型能力内化是核心竞争力：不再是前置意图识别的低效模式，而是直接在工作流中融合 GPT、翻译、评级优化等能力
  4. 云端优先避免踩坑：新手从云端版本开始（无需本地环保配置），再逐步掌握 1.0→2.0 迭代逻辑
  5. 围炉会议 + 一对一问答：社区学习路径清晰，从教程文档到大佬直播再到技术问答，完整的知识传递闭环
  6. 橱窗收益模式明确：月结排行榜激励机制清晰可见，应用优化→用户增长→收益提升的正向循环
  7. 邀请码 + 直播截屏：2.0 内测通过视频号评论区打"MyShell"截屏发放，降低入场门槛，促进开发者生态繁荣
