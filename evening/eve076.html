智能体基础与官方应用学习

1/4

本次共学以阿里云百炼应用广场为参考，深入讲解如何制作属于自己的智能体应用。讲师以「鲁迅文风转换助手」等官方应用为案例，详细演示了从应用测试→应用复制→配置优化的完整流程。

核心环节包括模型选择（如千问 235B）、提示词优化、参数调整等，强调通过角色设定、语言风格、限制条件的组合来减小大模型幻觉，提高输出质量。

创意智能体设计与落地应用

2/4

智能体创新玩法多维展开：

  • 名人角色创新：孙悟空背古诗、猪八戒美食搭子等角色混搭
  • 身边人物创意：损友角色、学习督促者等贴近生活的智能体
  • 硬件接入：将智能体部署到桌面机器人，增加交互趣味性

调香智能体案例展示了视觉模型 + MCP 协议的高阶应用——用户上传图片后，智能体结合视觉理解能力完成香水设计、商品推荐等多环节任务。

创意延伸方向覆盖烘焙、调酒、奶茶养生、花束设计、室内改造等落地场景，强调以官方模板为参考而非直接照搬。

工作流与多维表格深度融合

3/4

钉钉/飞书多维表格与百炼工作流的打通实现了批量自动化处理的能力：

工作流搭建步骤：新建工作流 → 加入大模型节点 → 设置用户提示词 → 选择目标语言 → 发布获取应用 ID

表格配置：复制应用 ID 和 API key 到多维表格 → 设置输入参数 → 保存后可批量生成翻译内容

图像生成应用展示了从单张手帧图生成多张分镜、进行动作设计的完整流程。推荐使用千问 Image Edit 模型或谷歌 AI Studio 进行图像处理。

💡 核心洞察：在 AI 应用创作时代，不需要从零开始。参考官方应用的提示词逻辑、工作流结构、角色设定等要素，基于深度理解进行改进和创新，才是高效学习与快速迭代的正确路径。工作流与表格的结合让自动化处理从技术专家的专属工具变成全民能用的生产力平台。

🎯 核心要点速记

  1. 学习路径明确：先在应用广场测试官方应用 → 复制应用到自己的工作区 → 拆解提示词、模型、参数配置 → 基于理解进行改进创新
  2. 智能体创意无限：从名人角色、身边朋友、角色混搭出发，配合配音功能实现多模态交互，可接入硬件扩展应用场景
  3. 提示词优化是关键：角色+技能+语言风格+限制条件的组合能有效降低大模型幻觉，使用 AI 优化功能迭代提升
  4. MCP 协议赋能进阶：联网搜索、图生图、万象生成等 MCP 工具可在应用中自由组合，轻松实现复杂多步骤任务
  5. 表格自动化新范式：钉钉/飞书多维表格 + 百炼工作流 = 零代码批量处理，翻译、图像生成、数据分析全覆盖
  6. 文档撰写有规范：涵盖演示效果、创意延展、实现原理，重点突出完成度和实用空间，社区提供模板可直接复用
  7. 社区支持与福利：完成作业获结业证书，成为先锋官解锁隐藏福利；搭子群帮助相互监督进度，资源共享高效成长
