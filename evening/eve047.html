豆包应用创作挑战赛冲20万大奖指南

讲师：许键 时间：2025年11月12日 19:54-21:58
WaytoAGI晚8点共学

赛事核心机制

零门槛创意竞赛 | 多元奖励体系

办赛理念：不写一行代码，无需编程基础，只要有想法和创意就能参与。无论学生、新人还是职场人员，都可将奇思妙想转化为实际作品。

参赛方向：

  • 创意类：无主题门槛，纯比拼创意
  • 公益类：乡村课堂教学、银发数字友好、青少年健康成长三大赛道

奖励设置：

  • 金奖5名：1万元 + 火箭发射观礼 + 创作派对邀请函
  • 银奖：5000元 + 迪士尼&环球影城双人票
  • 铜奖15名：创作派对邀请函
  • 盲盒奖励：100-2000元随机掉落（电饼铛、机票等）
  • 最佳公益应用奖：Apple Watch

应用创作三大方法

模板 | 工具提示词 | 生活场景

方法一：模板快速搭建

  • 多种预设模板（偶像应援站、小飞机大战、像素游戏等）
  • 点击即用，仅需替换风格和背景
  • 适合零基础用户，快速降低开发成本

方法二：工具+提示词优化

  • 参考图功能：上传UI参考图帮助大模型理解
  • 画板功能：手绘界面 + 文字说明辅助需求表达
  • 提示词宜清晰简洁，利用优化按钮让大模型按软件工程方式改进
  • 问题修复：通过截图反馈让大模型一件件修复（避免同时修复多个问题）

方法三：从生活场景挖掘创意

  • 血糖管理计算器、温度穿搭推荐、食谱规划器等解决实际问题
  • 参考他人创意激发灵感，但着眼于未被满足的生活需求

投稿全流程（1小时搞定）

应用编辑 → 选择分类 → 投稿发布 → 表单提交

第一步：应用编辑

  • 选择历史版本中的应用进行投稿
  • 编辑名称和描述，增加吸引力
  • 利用豆包生成相关封面图

第二步：分类确认

  • 选择应用分类（创意类/公益类）
  • 确认参加创作挑战赛并同意赛事规则

第三步：投稿发布

  • 点击投稿发布到创作广场
  • 在投稿界面获取投稿链接

第四步：表单提交

  • 将投稿链接填入活动页表单
  • 填写昵称、联系方式、邮箱、应用名称等信息
  • 每天最多提交3次，无总次数限制，可多次提交不同应用

实战案例与优化迭代

双人连线游戏 | SmartTodo待办应用 | 多类型应用包装

案例一：双人连线游戏

  • 创作：画板手绘九宫格 + 简单提示词"做一个双人连线游戏"
  • 迭代：通过截图反馈不断增加规则（限制棋子数、随机删除等）
  • 优化：修改游戏名称和规则说明，提升趣味性和可玩性

案例二：SmartTodo待办事项

  • 功能：任务管理、过滤、SMART原则检查
  • 问题修复：按钮不可点 → 过滤无效 → 界面中英双语化
  • 启示：版本一虽有缺陷，但通过逐步修复可达可用状态

多类型应用的公益包装方案：

  • 英语错题集 → 乡村课堂教学场景
  • 数字冒险游戏 → 结合教学调动学生积极性
  • 消消乐游戏 → 老年人智力开发（银发友好赛道）

💡 不写一行代码也能冲20万大奖的核心秘诀：用生活中的真实问题作创意源头，通过与大模型的多轮对话快速迭代，最后根据公益赛道灵活包装应用方向。组队+界面设计+迭代优化=获奖高概率。

— 许键

核心收获（5条）

  1. 零门槛参赛：不需要代码基础，有想法就能用豆包应用创作挑战赛平台快速实现，模板+提示词+画板三大工具覆盖所有创作需求。
  2. 多轮迭代是核心：首版应用即使有bug也不要放弃，通过截图反馈、逐项修复，大模型可以逐步优化功能和界面，提升应用完成度和可玩性。
  3. 公益赛道是加分项：同样的应用创意（如游戏、工具），包装成乡村教学、银发友好或青少年成长场景，获奖机会大幅提升。
  4. 组队参赛效率高：理想配置为1名创意产品经理+2-3名执行力强的技术/内容人员，分工协作能有效提升作品质量和投稿效率。
  5. 投稿全流程仅需1小时：从应用编辑→分类选择→投稿发布→表单提交的完整流程标准化，每天可投3次，无总数限制，鼓励多次尝试不同创意。
