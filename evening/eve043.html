豆包应用创作赛进阶攻略实战指南

⏱️ 2025年11月24日 19:55-21:57 👤 主讲：axshui 直播回放

#1 创作灵感与应用方向

热门趋势与新方向

  • 房贷计算器类应用竞争加剧，优质想法需尽快实施
  • 五险一金相关应用成为新兴创作方向

游戏与娱乐类灵感

  • 功德类游戏、单词消消看、五子棋、女巫毒药游戏
  • 怪物吃单词游戏（可双投乡村教育赛道）、滑板挑战、跑酷游戏
  • 技术限制时换思路：宠物打分难实现 → 做记录宠物日常的网站

公益赛道创作方向

  • 乡村教育：学音标网页（带字母读音+卡通图）、历史人物解说、天文/化学/物理公式网站、植物/昆虫百科、答题积分兑换
  • 银发群体：退休倒计时、药品查询、防诈指南、听障辅助、老年痴呆防护应用
  • 情绪解压：树洞匿名发泄、梦境解析、烦恼清理网站

灵感获取方法

生活中随时记录想法到备忘录 → 积累后用AI工具或豆包优化提炼

#2 应用创作与优化的核心技巧

标准创作流程

  1. 进入创作页面 → 点击"立即创作" → 输入想法
  2. 点击"优化指令" → 豆包优化提示词 → 根据需求修改
  3. 点击"发送" → 豆包生成作品

自然语言修改与优化

  • 通过自然语言描述需求（修改标题、添加动画效果等）
  • 关键技巧：在指令后加上"确保完成修改后再检查一遍，没问题了再发给我"，让AI自查避免bug

UI设计优化方案

  • 使用豆包内置模板，或从Figma、Framer等网站截图参考样式
  • 让豆包按照目标风格进行设计制作

音频功能实现

在网上查找在线音频资源链接 → 让豆包添加到应用中 → 若链接无法播放，让豆包重新查找可用链接

处理功能问题的黄金法则：让AI在完成修改后自我检查一遍，这样能大幅降低替换操作未生效等问题的发生

#3 比赛规则与投稿完全指南

比赛赛道设置

  • 常规赛道：可创作任何类型应用
  • 公益赛道：导航页、工具、游戏网页、网站等

关键限制条件

  • 每个账号每天投稿次数为3次
  • 公益奖评选要求：进入榜单前30或前100才有资格进入评委评选环节

完整投稿流程

  1. 进入投稿页面 → 点击"立即创作"完成作品
  2. 点击"投稿" → 选择应用名称、填写应用描述、上传封面图、选择分类
  3. 阅读参赛信息并确认后点击"确定投稿"
  4. 点击"我的投稿" → 查看详情并复制链接
  5. 填写表单：豆包投稿昵称、联系方式、邮箱、应用名称、应用描述、应用封面图

时间提醒

参会者需在12月8日前完成作品投稿

#4 典型作品点评与优化建议

童心天空 — 语音功能优化

  • 问题：语音功能存在循环播放问题
  • 建议：调整为只播放一次，或点击空白处停止

情绪绘本共育平台 — 名称+视觉升级

  • 名称缺乏吸引力 → 使用提示词模板修改为更温馨有趣的名字
  • 背景优化 → 添加星空和闪耀颜色，增强情绪感受

龙哥的房门 — 功能与动效提升

  • 功能简单 → 增加动画效果（会动的钟、SVG动画）
  • 完成倒计时后 → 给出带图片的卡片反馈

诗词大咖挑战赛 — 名称创意+赛道选择

  • 改为更有梗、好玩的名称提高吸引力
  • 推荐投稿公益赛道，适合乡村教育

方言守护者 — 声音功能优化

  • 声音功能存在问题 → 使用后端模型（如Trae）优化声音识别和播放

生肖捉迷藏 — 多维度优化

  • 声音效果不佳 → 考虑更换声音模型
  • 增加鼠标移动时的图案动效，提升观感
  • 添加迷宫背景图，增强游戏趣味性

长篇小说上传分析 — 功能完成度提升

  • 增加模板或文字输入框方便用户测试
  • 优化删除和更改功能
  • 使用提示词模板修改名称，使其更有吸引力

躺平计算器 — 内容丰富度

  • 功能简单 → 增加内容使其更丰富
  • 使用Figma或Framer优化UI界面，提高美观度

凯格尔运动训练 — 创意肯定

  • 创意和功能获得肯定，鼓励参赛
  • 期待未来接入更好听的声音模型

💡 好想法的时间窗口有限——房贷计算器已经出现竞争，五险一金是新机会。记住：优质创意不是你有，而是你快速执行的时间优势。

📌 核心要点速记

  1. 灵感来源最大化：生活→备忘录→AI优化→作品，建立持续的想法积累机制，不要期望灵感突然降临
  2. 优化指令必备技巧：每次修改后加上"自检确认"指令，让AI主动查漏补缺，减少人工返工
  3. 公益赛道的双投机会：某些应用（如教育游戏）可同时投稿常规+公益赛道，扩大曝光和获奖概率
  4. UI设计不用从零开始：参考Figma/Framer等设计网站截图，让豆包按样式复制，省时高效
  5. 音频链接失效的解决方案：不要换工具，让豆包重新查找可用链接，保持应用完整性
  6. 投稿前的三重检查：功能完整度→UI美观度→文案吸引力，缺一不可，决定初筛通过率
  7. 时间节点硬约束：12月8日前投稿，给优化和评审留出充足时间，不要踩线提交
