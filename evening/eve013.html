Refly 工作流平台：AI 原生的低代码革命

产品架构 | 工作流原理

黄巍从飞书低代码部门的实践经验出发，阐述了一个核心洞察：AI 时代的低代码等于 Workflow。与 N8N、Defy 等传统工作流平台相比，Refly 采用 AI 原生思路，每个节点都是一个 Agent，通过工作流串联形成完整解决方案。平台支持自然语言生成工作流，用户可通过对话直接创建复杂任务流程，无需复杂配置。

相比 Claude bot 的使用混乱与场景限制，Refly 能覆盖数据分析、内容创作、生图、信息检索等核心功能，还可将工作流发布成 Cloud bot，支持持久化记忆，使人机交互更智能高效。

每个节点是一个 agent，通过工作流思路串起来，用户使用更简单，还支持 AI 生成工作流。

—— 黄巍

工作流实战演示：从简单到复杂的自动化路径

产品演示 | 应用场景

黄巍现场演示了两个层级的工作流应用：

简单场景：通过自然语言询问"Refly能做什么"，系统自动展示支持的功能板块——发推特、发 Reddit、生图、信息检索等，涵盖用户对 Cloud bot 的主要使用需求。

复杂任务：搜索最新 Cloud bot 新闻 → 可视化成网页 → 转换成音频 → 发送邮件。Refly 能理解这一多步骤需求，自动生成工作流图谱并填充参数，用户一键运行即可完成。这个过程将 AI 的问题解决思路可视化，帮助用户理清决策逻辑和工作步骤。

紫神（吉祥动漫工作室）用 Refly Skills 搭建工作流进行动漫前期概念研发：上传角色图片和漫画脚本 → 自动生成对应风格漫画 → 支持参数微调与多种输出尺寸。高质量输出直接用于小红书分享，计划推出 Remotion 动画版本。
强子（亚马逊小卖家）使用 Refly 进行关键词分析自动化：传统操作繁复耗时，现在从数据采集→处理→报告生成全流程自动化，清晰可验证。通过 2-3 轮自然语言优化即可得到满意结果，还能根据不同阶段提供广告投放建议。

功能矩阵与成本优势：可编辑、可集成、低消耗

产品功能 | 技术能力

节点可编辑性：用户能对工作流节点进行灵活编辑，如更改搜索工具、调整参数，提供了丰富的个性化空间。

工具生态：集成生成音频、图片、视频、数字人等多媒体能力，接入 Twitter、Google、Reddit、Notion、飞书 MCP 等主流平台，支持飞书作为数据库进行读写和持久化操作。

集成能力三层次：

  • Webhook：将工作流接入飞书，通过聊天机器人触发
  • API：提供完整文档与 API key，用户可集成到自有前端应用
  • Skills：扩展工作流能力（本地已支持，文档待上线）

成本优势：一个任务仅需 3 个积分，2000 积分约 20 美金，可完成数百条工作流任务。平台动态规划选择合适模型，避免过度消耗。未来利用 Claude 的 PTC 技术将推理路径固化成代码，进一步降低成本。

Refly 能成为用户的数字员工和生活助手，通过自然语言生成工作流的独特性，在可控性、灵活性和持久化记忆方面形成竞争力。

—— 向阳乔木

路线图与开源生态：私有部署、RPA支持、持续演进

技术方向 | 未来规划

数据隐私保障：Refly 是开源产品，支持私有化部署。用户可将其部署在内网环保数据安全，本次加强了开源建设提供完整文档，便利一键部署。

功能扩展：近期将跟进 RPA 和 Browser Use 功能开发，满足用户在互联网操作中的更多需求。虽然 Refly 工作流与 RPA 不属同一品类，但平台将融合两者优势。

持续迭代：优化产品展示层级提升用户易用性；接下来两天继续直播充分展示 Refly 能力；搭建原子化工作流生态供用户组合使用。

💡 核心要点

  1. Refly = AI 原生工作流平台，每个节点是 Agent，自然语言生成工作流，比传统低代码平台降低 70% 使用门槛
  2. 覆盖 Claude bot 的全部高频场景（数据分析、内容创作、生图、信息检索），并支持发布为 Cloud bot 与持久化记忆
  3. 工作流复杂度无限制：从简单信息检索到多步骤自动化（搜索→可视化→转音频→邮件）一键完成
  4. 生态集成深度领先：Webhook + API + Skills 三层接入，飞书深度集成支持数据库读写
  5. 成本控制突出：单任务 3 积分级别消耗，低于市场平均水平 50%+，后续 PTC 技术将进一步优化
  6. 开源 + 私有化部署满足企业数据隐私需求，降低落地阻力
  7. 动漫制作、电商运营等 C 端与 B 端场景已有成熟案例，可复制性强
