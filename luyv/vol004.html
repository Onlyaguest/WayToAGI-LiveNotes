SEC-01 产品核心理念
心流不应被工具切换打断——从生成到剪辑，一处完成所有创作

创作者的真实痛点在于：创作流程碎片化。想出一个镜头概念，要在 Midjourney 出图、Runway 生视频、PR 剪辑、再回到 ChatGPT 改文案……每一次切换都是一次心流的中断。OpenCreator 的回答是：把所有创意原子放进同一块画布。

Two one idea, all your needs — 一个创意，一张画布，全部搞定。 — 陈筱漫，OpenCreator 联合创始人
SEC-02 画布交互与核心功能

基础交互：拖拽 + 连线
左侧原子库按 文图 / 视频 / 语音 / 剪辑 分类，拖拽节点到画布上连线即构成工作流。每个 AI 模块可独立切换底层模型，一键测试提示词对比效果。

两种运行模式

  • 🔬 单节点运行：点击原子右上角小按钮，单任务测试，调参选型用
  • 🚀 全局批量运行：点击右上角大 Run，整条工作流批量产出，专业团队批量制素材首选

能力矩阵

  • 文字：文生文、文本分裂（脚本→镜头提示词）
  • 图片：文生图、图生图、风格一致生图、去背景、高清化、图片描述
  • 视频：文生视频、图生视频+音效、视频高清化、对口型
  • 音频：背景音乐生成、TTS 人声（接入 Eleven Labs、Fish Audio）
  • 剪辑器：轨道裁剪、音画合成、标题添加、平台尺寸适配

已接入模型：GPT-5 等文字模型 · Flux / 集梦 等图像模型 · 多家视频模型 · Eleven Labs / Fish Audio 语音模型

SEC-03 二创生态与资产管理
Let me remix it — 把工作流分享给队友，创作不再从零开始。 — 陈筱漫

资产区域（Assets）支持三类存储：

  • 📁 历史生成结果：视觉 / 音频 / 文本，全部可溯源
  • 🔧 工作流模板：保存原子组合及参数，下次直接拖入画布复用
  • 🔄 二创分享：团队成员基于同一工作流修改参数，无需重新搭建

社区化愿景：团队希望 OpenCreator 成为创意工作流交流平台，让创作者可以分享、交易和 Remix 彼此的工作流，形成创意飞轮。

SEC-04 定价策略与实战成本

三梯度低价方案（按素材生成量区分）

  • 第一梯度参考量：约 40 个 0.16s 视频 + 135 个 Flux 图像
  • 建议新手先单节点测试调参，确认效果后再批量运行，兼顾效果与成本控制

典型工作流成本拆解（经典视频创作流）

  • 声图声纹单元：token 消耗极低
  • 文生图：有价格梯度，可选型控制
  • 图生视频：因厂商 API 不同，成本差异较大
  • 全流程合计：约 2–3 美元/次
SEC-05 团队、上手路径与招聘
模型接入不是壁垒，场景泛化与工作流复用才是真正的护城河

三人团队（"三角形"）：陈筱漫 · 小艺 · 大海
源于自身创作痛点——纽约广告公司案例与创意比赛经历，决心为创作者打造包容、接纳的一站式平台。
当前招聘方向：全栈开发 / 市场 / 运维，简历投递见 waytoagi.com 鹿演第四期文档。

新用户入手路径

  1. 访问 opencreator.io，点击 Start for Free
  2. 从 Templates 模板开始，点击 Make it Yours 修改参数
  3. 熟悉后选 Start from Scratch，自建工作流
  4. 官方 YouTube（Open Creator）及微信视频号持续更新教程

支持 QQ 邮箱 / 谷歌邮箱注册，无需翻墙，推荐 Chrome 浏览器。

核心要点 Takeaways
  • 产品定位OpenCreator 是面向内容创作者的一站式 AI 画布，以 Workflow 形态将文图视频音频剪辑全流程整合，消灭工具切换造成的心流断裂。
  • 核心交互拖拽原子节点 + 连线构建工作流，支持单节点调试与全局批量运行两种模式，兼顾探索与规模化生产。
  • 二创壁垒工作流可保存为模板分享给队友，支持 Remix 二创，团队协作不再从零开始，形成创意复用飞轮。
  • 成本控制典型视频创作全流程约 2–3 美元；建议先单节点测试选型，调好参数后再批量，兼顾质量与预算。
  • Workflow vs Agent当前选择 Workflow 形态是因其更直觉还原心流交互，可灵活调整单一节点参数，未来不排除结合 Agent 能力。
  • 真正护城河模型接入是基础，核心壁垒在于场景泛化——让用户因效果好或工作流复用提效而形成使用粘性。
  • 上手建议新手从模板入手，基于成熟 SOP 快速出效果；进阶用户从空白画布自建，先粗测原子能力再批量运行。
  • 团队招聘三人小团队，急需全栈开发、市场与运维，感兴趣可至 waytoagi.com 鹿演第四期文档查看联系方式。
