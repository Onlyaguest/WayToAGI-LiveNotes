Refly.AI 正式公测
小白版工作流平台
如何封装你的个性化经验

主讲：黄巍（Tom）· Refly 创始人 CEO WaytoAGI 晚8点共学 时长：2h12min
鹿演 Vol.006 · 2024.12.10
SEC-01 产品起源：从飞书低代码到 Refly 创业
AI 出现之后，我们团队成为国内最早探索 AI + 低代码平台的一批人，在飞书内部打造了飞书智能伙伴创建平台（对外称 aily）。
—— 黄巍 / Refly 创始人

早期探索：黄巍曾在飞书参与低代码平台研发，深度实践 AI + 低代码融合边界。

创业契机：基于飞书 aily 项目积累，团队出来创业做 Refly，最初以画布为核心产品形态。

产品演进：发现纯画布难被大众接受，转而探索 AI Agent + 画布结合，形成 5-8 个节点解决具体问题的工作流模式。

融资情况：团队约 10+ 人，已获朱啸虎投资。

SEC-02 核心理念：自然语言驱动，经验封装分发
让优秀经验像软件一样被分发和消费

降低门槛：全程自然语言运行工作流节点，老师、学生等普通用户无需技术背景即可上手，真正的「小白版扣子 / n8n」。

先规划后执行：与传统 Agent 产品不同，Refly 先为用户生成自然语言工作流规划（含标题、步骤、工具），用户反复修改满意后再执行，节省时间和金钱。

上下文共享：每个节点都是独立 Agent，所有工具产生的结果可被后续节点完整共享，不丢失上下文，支撑复杂多步任务。

开源免费：个人开发者免费使用且可商用，欢迎社区贡献代码。

🧰 工具矩阵：数百个工具覆盖生成代码、执行代码、生成音频、生图、生视频、搜索、飞书 MCP 操作等；支持上传文件（最大 50MB）

💰 成本极低：单次工作流运行约 0.04 毛钱，平台标注每次消耗积分，透明可控

SEC-03 应用场景：四大典型案例演示

📈 财经视角：深层抓取巴菲特投资数据与市场发言，以其视角点评某只股票，为股民提供投资参考

📬 信息订阅：定期抓取 Product Hunt 文章 → 加工处理 → 生成文档 / 播客 / 视频 → 定时发送邮箱；满足打工人和学生了解科技热点

🔥 自媒体运营：监控微博 / 抖音热榜选题 → 自动撰写文章 → 多平台发布（飞书群、小红书、Twitter），帮助自媒体从业者批量提效

🗂 数据处理：接入飞书 MCP 服务，纯自然语言操作多维表格，创建、填充、整合数据库，开箱即用无需复杂配置

Refly 不只是要让大家使用工作流，更希望把每个人的经验封装成可复用的流程，让别人只需修改邮箱、参数，就能直接复用你的思路。
—— 黄巍 / 演示环节
SEC-04 产品定位与商业模式
披着工作流外壳的 AI 原生小红书

产品定位：介于 Manus / Genspark（解决复杂场景）与小红书 / 抖音（轻量消费）之间——Agent 场景下的内容消费平台，用户低成本购买和使用他人封装好的工作流模板。

vs 竞品：Make / n8n 门槛高、配置复杂；Manus / Genspark 重而贵；Refly 主打「三步操作」——填邮箱、输文字、点运行。

PMF 指标：① 达到 100 万美金收入；② 平台模板数量超过 10 万个且均有价值。

💡 创作者大赛：每两周根据工作流运行次数排名，前几名获数千美元奖金

💡 普通人变现路径

  • 监控 Reddit / Twitter 赚钱帖 → 批量发布 → 开通会员获流量费
  • Youtube / TikTok 带分销链接 → 销售佣金
  • 打包小工具录课售卖（社群有人做到不错收入）
SEC-05 融资经验 · 未来展望 · 参与方式

拿融资的核心要素（黄巍分享）：① 项目具备稀缺性和独一无二性；② 价值杠杆足够高（工具能帮很多人产生高价值产出）；③ 可借助 FA 机构（原力资本、深度资本）将想法转化为可投资项目。

产品未来：使用更便宜的模型持续降低使用成本；沉淀濒临失传的古法技艺（如中医疗法）以数字形态复用；开拓海外市场为核心增长方向。

🎟 激活码：微推 AI 群或官网路演页面直播群领取

📤 投稿流程：新建工作流 → 运行 → 发布成模板 → 发布到市场 → 审核通过参与创作者大赛

👥 招聘：设计 / 增长 / 产品 / 研发全面开放，欢迎对 Refly 感兴趣的同学投递

核心 Takeaways
  • 核心差异先生成自然语言规划让用户确认，再执行工作流——这是 Refly 与其他 Agent 产品最关键的区别，大幅降低试错成本。
  • 门槛革命全程自然语言操作，无需了解节点配置，真正实现「三步用完一个复杂工作流」。
  • 经验即资产工作流可封装个性化经验像软件一样分发，创作者可通过运行次数排名获得奖金变现。
  • 上下文不丢所有节点共享同一上下文，这是支撑多步复杂任务的底层技术保障。
  • 开源商用产品开源，个人开发者免费且可商用，极低的使用成本（单次约 0.04 毛）构建普惠基础。
  • 竞品定位不与 Manus 抢复杂场景，专注做「Agent 版小红书」——轻量、低价、模板化消费。
  • 融资方法论稀缺性 + 高价值杠杆 + FA 机构辅助，三要素缺一不可；推荐原力资本和深度资本。
