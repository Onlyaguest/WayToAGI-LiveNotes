SEC-01 产品定位：陪伴式 AI 创作助手

Creaibo 定义为 AI 创作空间，但核心理念更接近"陪伴用户成长的创作助手"。产品强调个性化优先——让用户成为 AI 内容的主人，而非被 AI 喧宾夺主。

  • 冷启动：用户一句话介绍自己 → 后续改为兴趣标签选项，降低操作门槛
  • 个性化助手 Able：基于用户上传数据生成初始形态与 MBTI，可做写作风格分析
  • 风格系统：支持更新自定义风格 / 使用预置模板，数据量越大续写越像本人
在 AI 时代，我希望为有追求的内容创作者提供好的环境和工具——让创意比提示词更有价值。
— 图灵的猫（rain）
SEC-02 核心功能：从灵感到分镜的全链路

画布 · 灵感可视化

  • 可粘贴网页内容、视频链接，上传文件；盲盒功能可随机抽取灵感卡片
  • 灵感与用户历史创作内容关联，非大模型随机生成，可视化后在后台易记忆

编辑器 · 大纲骨架写作

  • 大纲作为"骨架"，解决大模型写作不像用户风格、容易跑题两大痛点
  • 续写功能：基于用户框架 + 个性数据，模仿用户表达方式；支持快速模式 / 改写模式
  • 知识库：分公开 / 私有两类，写作时 AI 自动查证；优质上传者获得点数奖励

多模态 · 素材到视频

  • 集成搜索工具找素材，找不到时 AI 生成；支持图文、音效，视频素材支持即将上线
  • 一键生成分镜：包含首尾帧 + 参考图，运行后形成完整视频（测试版下月上线）
  • 图片生成、配音、BGM 生成；音色可自定义；后续可能接入播客音频 API
  • 资产界面统一管理，一键下载；未来支持打包成 PR / 剪映可导入格式
SEC-03 产品问答：适用场景与版本差异

国内版 vs 国外版

  • 国内版：内测中，需邀请码，部分模型未完善；适合可灵 / 即梦用户
  • 国外版：无需邀请码，适合高质量视频 / 播客创作者先行试用
  • 价格：头部模型折扣计入订阅费，与官网 / 官方 API 价格相近；正常订阅可支撑 50-100 个项目

适用内容类型

  • 当前版本支持时长：不超过 10 分钟；图文作者转视频建议尽量短
  • 动画剧本：句首注明剧本类型 / 风格 / 格式 + 开启续写，导入 OYOY 动画生成工具效果佳
  • 未来拓展：媒体领域带货文章、营销广告文案；B 端接入播客公司 API 及 B 站动态接口

产品核心壁垒

  • 技术壁垒：个性化算法（类木桶效应，补足最短板）
  • 认知壁垒：创始团队对内容创作的深度理解，难以被纯技术团队复制
  • 设计原则：让用户始终是创作主体，避免 AI 反客为主
SEC-04 创业感悟：内容原创与长期主义
创意比提示词更有价值——这是我们创业的核心信念
  • 创业驱动力：对内容原创质量的极致追求，而非商业逻辑驱动
  • 百大 UP 身份：创业初期正向激励、吸引 VC；但产品本身够好才是关键，不依赖创始人光环
  • 内容创作观：不应因曝光而做内容；以影视飓风为例，长期复盘迭代才是正道
  • 困难时刻：从媒体工作室转型做产品，工作流颠覆 + 长期 debug；用户用产品做出爆款是最大动力
  • 团队文化：扁平化共事，成员认同所做之事比技能更重要
  • 产品期望：外界评价"好玩有趣、能帮用户做成事"，无需颠覆世界
用户用产品做出了爆款内容——那一刻让我觉得所有的坚持都值得。
— 图灵的猫（rain）
SEC-05 核心要点总结
Takeaways · 本期精华
  • 定位Creaibo 不只是 AI 写作工具，而是基于用户个性数据的陪伴式创作助手，用户数据量决定个性化深度
  • 大纲骨架大纲机制是解决"AI 写作跑题 + 不像本人"的核心设计，让大模型在框架内发挥，而非自由生成
  • 知识库公开知识库共享生态 + 点数激励，写作时 AI 自动查证引用，显著降低研究成本
  • 多模态链路从文本到分镜到完整视频一站式生成，视频测试版下月上线，未来支持 PR/剪映导入格式
  • 版本选择高质量视频/播客创作者优先试用国外版；偏好可灵/即梦的用户等国内版内测开放
  • 壁垒本质个性化算法是技术壁垒，但创始团队对内容创作的理解才是最难复制的核心护城河
  • 创作哲学不因曝光做内容，长期复盘迭代终获回报；AI 时代让创意本身的价值高于 Prompt 技巧
