SEC-01

训练营概况与目标体系

筛选人才 · 形成生态

第二期核心目的是筛选更多AI人才，满足背后众多企业需求，形成人才正向循环。课程免费提供，期望学员形成良好学习氛围，共建AI开源知识库。

SEC-02

10分钟智能体搭建实战

从零到一的快速路径

COZE平台被推荐为初学者首选。操作流程：

  1. 点开发平台 → 左边创建智能体
  2. 输入提示词 → 蓝色图标优化
  3. 右上角发布 → 勾选目标平台
  4. 飞书需授权绑定完成发布

进阶操作：支持知识库、插件、工作流拼接，知识库支持多种格式（飞书文档、PDF等）。

初学者vs进阶者

初学者标准：用COZE搭建智能体，争取10个用户使用，提交智能体链接至作业文档。

进阶者挑战：

  • 发布到飞书、企业微信、小程序等多平台
  • 优化提示词、知识库、工作流各模块
  • 评测智能体准确度与性能
  • 探索不同模型效果对比

📌 截止时间：11月25日晚12点前提交，优秀作业将在知识库展示。

SEC-03

AI智能体的三大应用维度

横纵向+突破型能力模型

X轴：横向批量处理

  • 顶端新闻内容自动打标
  • 大健康平台热点文章批量生成
  • 企业数据批量化处理

Y轴：纵向知识挖掘

  • 和府捞面评论深度分析
  • 七匹狼销售话术引导优化
  • 后端API调用实现深度知识萃取

Z轴：向外扩展突破思维

  • 生成创意素材与文案
  • 突破能力边界的创新应用

高价值场景优先策略

企业应用AI面临的现实：投入大、场景难寻、收益有限。钉钉案例显示，80万一体机+定制智能体投入后，发现招聘员工做简单对话更经济，试运行效益有限。

破局方案：先从高价值场景小成本试点入手，验证效果后再加大投入。避免陷入"既怕数据安全又在投入决策上循环扯皮"的悖论。

必须重视的安全隐患

AI存在生成虚假内容的风险，如"林黛玉倒拔垂杨柳"等不符合事实的输出。企业应用可能导致低质问题。

解决方案：

  • 通过RAG（检索增强生成）添加知识库
  • 引入人工审核与把关机制
  • 使用弱智八等数据集进行模型评测
  • 定期对比不同模型性能优劣
SEC-04

平台生态对比与选择指南

三大阵营对标

🤖 智能体平台（一问一答型）

  • 字节扣子、阿里百炼、钉钉AI助理、百度AppBuilder、AWS
  • 特点：快速部署、开箱即用

⚙️ 低代码平台（可视化构建）

  • COZE空间、阿里相关平台、百度秒搭
  • 特点：文字输入即可完成如建博客等复杂任务

💻 高代码平台（开发灵活性）

  • Dify、Coder、百度文旭快码、Amazon Queue Koala
  • 特点：生成代码供编辑，或支持无代码使用

不同学员的最优路径

✅ 初学者：COZE平台
操作相对简单，线上即用，适合5-10分钟快速上手。

🚀 进阶者：Dify + N8N
考虑私有化部署，但技术门槛高。需综合评测平台性能、模型选择、数据集管理。

🏢 企业级应用：
需考虑：基础设施、模型选择、数据安全、私有化部署成本、性能评测。

💡 核心要点速记
  • 课程设置8节直播课程+自习室答疑，课程免费但收作业，11月25日晚12点前提交优秀作业，11月30日晚前提交所有8次作业才能获得结业证。

  • 知识库赋能添加产品文档、公开数据等知识库，使AI智能体更懂用户特定场景，通过RAG机制提升准确性和安全性。
