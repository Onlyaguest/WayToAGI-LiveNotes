SEC-01

工作流核心设计：从手工到自动化

手工制作小红书图文需要约1小时，包括AI生成文案、图片规划、生成提示词、AI生图、排版发布等多个环节，机械重复且低效。

通过N8N工作流自动化，完整流程压缩至2-3分钟，生成10篇笔记仅需5-10分钟。工作流将一小时的手工流程转化为高效的自动化执行。

"做商单的关键在于快速理解客户需求，将已有解决方案灵活改造为客户想要的案子。"

— 林琼（gleamist）
SEC-02

工作流六大核心模块拆解

模块一：主题输入
从飞书多维表格读取待处理数据

模块二：文案生成
使用DeepSeek大模型生成符合小红书风格的文案

模块三：智能内容分段
按平台特性自动分割内容结构

模块四：设计封面
AI生成创意设计提示词

模块五：图像生成
调用火山引擎即梦API完成图像生成

模块六：数据上传
存档至飞书多维表格并标记为已完成

"子工作流可实现并发处理，避免串行等待时间，将重复复杂操作独立抽离，通过主工作流下达具体任务，大幅提高工作效率。"

SEC-03

HTTP Request与API配置要点

凭证配置方案
采用环境变量方式配置凭证更安全。在N8N Cloud上需手动复制火山引擎的Key和Access Key。

平台配置清单

  • 飞书开发者：创建自建应用 → 获取凭证 → 开通权限 → 发布应用
  • 火山引擎：开通即梦AI服务 → 实名认证 → 获取密钥
  • DeepSeek：配置用于文案生成

社区节点 vs HTTP Request
社区节点功能强大（一个可抵六个），配置简便。HTTP Request版本需手动配置凭证、TOKEN获取、表格解析等节点，复杂度更高但灵活性更强。

SEC-04

黑客松与商业变现路径

全球黑客松活动
10月25-26日，30多个全球城市同步举办（上海、日本、新加坡等）。优秀项目有机会获得10万奖金。活动挑选优秀作品进行全国线上路演，邀请投资人和大咖指点。

产品网站商业模式
通过Web Coding搭建前端框架，调用N8N工作流API，实现服务封装。支持权限管理机制，不同客户看到不同界面。异步操作模式支持持续提交任务，提高使用效率。

核心要点速查
  • 工作流设计每张多维表格若要在N8N上操作，都需与应用绑定，否则无操作权限
  • 子工作流机制子工作流是独立工作流，触发需由主工作流的特定节点完成，可跨工作流调用，指定Workflow ID即可
  • API赞助政策已争取Web Coding API赞助，学员需注册账号并将邮箱更新到作业记录中，API仅用于学习，严禁商用
  • 作业奖励机制基础奖励10美金，获取结业证书有额外奖励；优秀学员（20%比例）可获神秘大奖
  • 社区节点安装在账号设置里找到"Community Nodes"选项即可安装感兴趣的社区节点
  • 调试建议使用N8N Cloud版本时，AI辅助功能可直接解答节点用法，对新手特别友好
  • 环境变量管理凭证配置建议用环境变量确保安全，设置位置在左侧菜单第二个选项
