SEC-01 智能体六大核心要素与工作流体系

本次课程聚焦问题解决能力的培养，强调这并非天赋差异，而是一套可遵循的体系。薛临风回顾了智能体的六大核心要素：

六大核心要素（按重要程度）：
  • 大模型 - 选择合适的模型处理问题，注意平台局限性
  • 提示词 - 决定大模型能否准确执行，遵循"角色身份+角色任务+输出框架"
  • 工作流 - 体现产品和业务真正流程，多数场景稳定可靠
  • 技能 - 本质是封装好的工作流，享受插件生态优势
  • 知识库 - 帮助大模型回答问题，存储静态数据
  • 上下文记忆 - 增强对话连贯性和个性化体验

"表达力是AI生产力的关键。学员应按照完整框架练习，突破内容表达的禁锢。"

— 薛临风

SEC-02 多维表调用COZE工作流：实操全流程

课程核心实操环节演示了如何用飞书多维表调用COZE工作流，将数据驱动产品。

5步快速上手：
  1. 多维表配置 - 新建"链接"字段（字符串文本类型）存放URL
  2. 工作流触发器 - 在多维表左下角选择"点击按钮"触发，HTTP请求执行
  3. 获取API凭证 - COZE API管理中设置个人访问令牌，复制TOKEN保存
  4. 填写请求参数 - 获取工作流ID，设置请求头（含授权+content-type）和请求体（JSON格式）
  5. 数据绑定 - 用多维表"链接"字段值替换请求参数中的URL字段

"邪修思路就是用最快速的方法解决问题，避免陷入复杂的代码节点。关键是理解循环体的思维逻辑，通过实践反思来提升能力。"

— 薛临风

故障排查：检查工作流是否启用、授权是否正确、括号是否完整复制。

SEC-03 知识库 vs 数据库：场景化应用指南

维度 知识库 数据库
本质 帮助大模型回答问题 规范化存储与操作
数据类型 静态数据 动态数据（增删查改）
医院案例 疾病百科、药物信息 个人档案、症状记录
优化方向 向量检索精度 查询字段设置、时间格式匹配

实战要点：工作流中新增数据时可用插件获取时间戳；查询时需设置多个字段避免输出问题；使用日期转化插件解决格式不匹配。

SEC-04 结业路径与社区机遇

训练营成长阶梯：
  • 第一步 - 定期提交8节课作业 + 结业MVP作业 → 获得结业证书
  • 第二步 - 前10%学员 → 社区认证 + 能力档案 + 优秀学员榜单曝光
  • 第三步 - 持续参与社区 → 先锋官、助教、讲师机会
  • 第四步 - 超创计划 → 传播开发者/创作者版、项目交付、企业服务等

社区比赛机会：豆包应用生成比赛（20万奖励）、WaytoAGI×豆包创作挑战赛（11.10-12.08，最高10000元）、蚂蚁百宝箱（最高30000元）。

核心要点速记

  • 问题解决能力并非天赋，而是体系化的训练。通过实践-反思循环，刻意练习JSON、工作流等基础概念，能有效提升技能熟练度。
  • 工作流是智能体核心，承载产品逻辑的真实流程。大模型、提示词、工作流三者最为关键，需要反复打磨和测试。
  • 多维表+COZE联动实现数据驱动的自动化流程。关键是正确配置TOKEN、工作流ID、请求头和请求体参数，故障排查要检查启用状态和授权信息。
  • 邪修思路高效解决问题——选择循环+选择器+中间变量+大模型组合，避免复杂代码节点。理解循环逻辑是关键，可快速迭代和规模化处理。
  • 知识库存静态，数据库存动态。在工作流中直接调用数据库比多维表更高效，需注意查询字段完整性和时间格式转化。
  • 结业MVP作业是评选优秀学员的主要依据。系统思考产品逻辑，用五步法文档描述，有搭子可实现完整产品并补充详细文档。
  • 社区赋能与持续成长——优秀学员获得榜单曝光、认证、讲师等机会。关注飞书消息每日更新，及时提交作业和参与比赛，最大化资源倾向。
