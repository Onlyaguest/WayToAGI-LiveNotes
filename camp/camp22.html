SEC-01

N8N 核心架构：从触发到执行

本次训练营深入讲解 N8N 自动化工作流的三大核心节点体系。触发类节点包括手工触发（测试用）、定时触发（灵活的时间规则）、表单触发（自定义用户交互）、Webhook 触发（连接第三方应用）；AI 类节点涵盖 Agent 智能体、模型节点、信息提取器、文本分类器、情感分析等；数据处理节点提供字段编辑、拆分聚合、过滤去重、HTTP 请求等能力。

触发节点：6 种类型，定时触发最常用于日报周报
AI 节点：7+ 种，Agent 节点功能最强大
数据处理：20+ 种，HTTP 请求节点最关键

课程强调 NPM 本地安装方案最适合新手——仅需安装 Node.js LTS 版本，终端运行命令后访问 localhost:5678 即可启动 N8N 浏览器界面。若遇问题可先用 Cloud 版本学习，后期可按需升级 Docker 或企业部署。

SEC-02

批量生图工作流：从提示词优化到自动循环

"用 PIN 方式锁定数据，既能实现批量自动化，又能显著降低 TOKEN 消耗成本——这就是 N8N 工作流的核心价值。"

批量生图工作流通过五个节点实现端到端自动化：①表单触发节点让用户输入提示词和生图数量（PIN 住表单数据）；②AI Agent 节点优化提示词，生成多套方案（用分隔符隔开）；③Code 节点按分隔符拆分提示词数组；④HTTP 请求节点调用豆包 4.0 模型发起绘图请求；⑤循环遍历节点按队列依次处理每张图片。

工作流前置准备：
  • DeepSeek 申请 API Key（充 10 元可用很久）
  • 火山引擎豆包 4.0 申请 API Key 和 HTTP 请求格式
  • N8N 中配置凭证，保存 API 密钥
  • 参考官方文档设置绘图参数（尺寸、水印等）

关键技巧：使用 JSON 方式传递请求体而非 URL 编码，避免 N8N 与火山引擎格式兼容性问题。提示词优化后拖拽替换原提示词字段，实现端到端的自动化生图链路。

SEC-03

自动发邮件工作流：定时聚合与结构化输出

新闻日报工作流展示了复杂数据处理的完整范例。首先通过 RSS 节点或 News API 获取新闻内容（用日期节点格式化筛选当天新闻，考虑时区偏差可获取前一天数据）；其次对原始数据进行清理——拆分 articles 数组、过滤标题含"AI"关键词、聚合合并结果；再次用 AI Agent 节点生成结构化日报（Markdown 格式）；最后配置时间触发规则（支持按秒/分/小时自定义）、Markdown 转 HTML 节点、邮箱发送模块（支持 Gmail、QQ 邮箱等）。

邮件配置关键点：
  • RSS 方案无需翻墙，国内可直接使用
  • Markdown 转 HTML 确保邮件样式美观
  • 邮箱 SMTP 配置流程（谷歌账户、QQ 邮箱等）待补充到课件
  • 激活工作流后按定时规则自动发送日报

这个工作流体现了 N8N 的核心价值：数据驱动 + 自动触发 + 智能输出，一旦激活即可完全自主运行，无需人工干预。
