SEC-01

Core Concepts：重构 AI 交互范式

本次训练营的核心突破点在于：从 GUI 对话框走向 CLI 工具链。传统的大模型只是"大脑"，而 Skills 通过封装 API 调用、本地脚本和提示词，让 AI 获得了"手"——能够真正执行任务。

两大执行环境对比：

  • Claude Code (CC)：官方命令行工具，深度优化shell执行，纯技术向
  • OpenCode：开源替代方案（8万+ Star），支持多模型切换（Ollama、DeepSeek），含Web UI，对国内用户友好

"Skills 本质不是代码，而是将复杂工作流程参数化、模块化，让大模型按需调度。"

SEC-02

四大屠龙技：歸藏的高阶 Skills 实战

① 动态 PPT 生成（含转场动效）

整合 Banana API + FFmpeg + 首尾帧提示词技术。核心创新是利用生成式转场在两张静态PPT间生成平滑炫酷的动画过渡。输出既有Web演示版HTML，也有可直接分发的MP4视频。

② YouTube 视频自动切片（yt-dlp + 大模型理解）

完全自动化长视频处理：下载 → 内容理解 → 语义切分 → 双语字幕生成 → 短视频导出。相比简单剪刀式切割，这套 Skill 是基于理解的精准萃取，适合快速搭建垂直资讯账号矩阵。

③ 智能文章配图（语义拆解 + 风格统一）

自动分析文章段落 → 判断最优比例（16:9 或 3:4） → 调用 Flux/Midjourney API 生成风格统一的配图（矢量、玻璃质感等）。支持一键生成带所有要素的封面。

④ 去 AI 味写作润色（反向规则库 + 评分迭代）

内置"AI写作黑名单"（否定词表、句式套路），逐句扫描生成文本 → 质量评分 → 智能修改。可输出适配"小红书"等特定平台的排版风格，本质是AI审核AI的闭环优化。

SEC-03

Listenhub 原生 Skill：从一句话到完整产物

Listenhub 官方 Skill 演示了"极简生产力"的可能性。通过自然语言指令，自动调用平台 API，完成端到端的内容生成。

核心产物三元组：

  • AI播客：生成双人对谈，包含辩证思维，可换声音、复制逐字稿、二次编辑
  • 解说视频：4K直出，自动匹配视觉素材，基于内容生成演讲稿
  • 深度研究模式：自动联网搜集资料，输出精美解说视频，无需用户投喂素材

示例流程："帮我做一期关于 Manus AI 进展的播客" → AI自动完成背景研究、脚本规划、音频生成、字幕配图，最终交付可发布的多种格式产物。

"2026年的人机协作新范式：AI不再仅仅是顾问，更是拥有'手'的执行者。Skills是赋予大模型系统化能力的关键——让模型不仅会思考，更会行动。"

—— 本次训练营核心洞察

核心要点速记
  • 工具选择新手推荐 OpenCode（开源、友好）而非 Claude Code；打破 GUI 幻觉，拥抱命令行才是 AI 时代的标配
  • Skills 创建进入"Plan Mode"（Shift+Tab）用自然语言描述需求，摒弃纯手写代码；模型自动规划架构、依赖和逻辑流程
  • 精准触发Skills 不好用的原因多半是触发条件模糊；需精确到步骤级的描述，避免万能化设计，聚焦垂类任务
  • 视频处理YouTube 切片 Skill 代表了"搬运+精加工"自动化的未来；可开发针对特定领域的自动切片 Skill，运维 10+ 高质量资讯号不在话下
  • 商业机会将粗糙 AI 稿件转化为"高情商人话风"的润色服务可商业化；还可封装成企业专属 GPTs 或 API 接口
  • 企业应用成为"企业私有 Skills 架构师"——将财务报表合并、合同生成、库存预警等繁琐工作参数化，打造真正的"数字员工"
  • 社区福利Listenhub 为 WaytoAGI 社区提供 Pro/Max 年费 75折，有效期至 2025/02/22；含全部权益（解说视频、PPT、播客、配音等）
